One word only: the verdict on a former partner. The ex was recalled, like a defective product pulled off the shelves.

> Recalled

## How it works

`main.py` (Python 3 standard library only) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: exactly one word, 1 to 111 characters of UTF-8 text.

```sh
python3 main.py
```
